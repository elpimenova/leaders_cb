Программа для лидеров Dodo Brands: как проводить сложные разговоры про Dodo Review, зарплатный цикл и Total Rewards.

## Артефакты

| Файл | Что это |
|------|---------|
| `Leaders×CB_Одностраничник.md` | Карта всей программы — для стейкхолдеров |
| `Leaders×CB_Welcome-комплект.md` | Первый документ нового лидера |
| `Leaders×CB_Микрокурс-Dodo-Review.md` | Микрокурс M0.2 — Dodo Review для лидера |
| `Leaders×CB_Гайд-ЗП-цикл.md` | Гайд M0.3 — зарплатный цикл, CR, контр-оффер |
| `Leaders×CB_Калькулятор-Total-Rewards.html` | Калькулятор M0.4 — совокупный доход |
| `Leaders×CB_Тренажёр-диалогов.html` | Тренажёр M0.5 — 8 сценариев сложных разговоров |
| `Leaders×CB_Пакет-HRBP.md` | Материалы для HRBP |
| `Leaders×CB_Метрики-и-DoD.md` | Метрики успеха и шаблон отчёта |
| `Leaders×CB_Дашборд.html` | Дашборд программы — обновляется вручную |

## Как использовать

**Markdown-файлы** → копировать в Тайм  
**HTML-файлы** → открывать в браузере напрямую или хостить через GitHub Pages

## Placeholders

Все цифры (CR-пороги, вилки, даты цикла, суммы бенефитов) помечены `[PLACEHOLDER]` и требуют подтверждения от C&B перед использованием.
